A  dynamic Task Manager and Productivity Tracker built with native web technologies. It allows users to efficiently manage their daily schedules through an intuitive CRUD (Create, Read, Update, Delete) workflow, category tagging, and status filtering.

Technology Stack  :
HTML5 . CSS3, JavaScript.

Project Structure
├── index.html     # Application interface, form fields, and filter layout.
├── style.css      # Custom styling sheets and structural alignments.
└── script.js      # Core logic, filtering mechanisms, and localStorage engine.
